Zero-Data UX Guidelines

Afoogy Design System Principles • Human Interface Standards
Compliance: Operational v2.4
navigation Never Leave a Dead End

Every empty state view must provide a single unmistakable primary call-to-action (CTA). Staff members should immediately know the first step without needing training.

token Minimal & Executive Imagery

Avoid exaggerated cartoonish mascots or oversized joyful vectors. Use structured geometric glyphs, discrete badge lines, and functional micro-indicators.

psychology Explain the "Why" & "Next"

Clarify the dependency cascade. For example, explain that batches cannot start until a curriculum is drafted, or that invoices populate upon enrollment.
